How we attribute a project to a developer

The DLD open feed does not carry a developer field. Dubai project names almost always carry the developer's name, so we match on that: "Azizi Venice 14" to Azizi, "Binghatti Skyflame" to Binghatti, "Shahrukhz by Danube" to Danube. It is a readable rule you can check yourself, and where a name gives us nothing we leave the project unattributed rather than guess. 38,734 of 69,386 sales in tracked projects are attributed this way.
